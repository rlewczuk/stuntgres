# Phase-one engineering contract

## Package seams

- Root `stuntgres`: database/sql driver, connectors, connections, statements, rows, results and native Reset/Dump/Restore APIs. `NewDriver() *Driver` implements DriverContext; default registration is `stuntgres`.
- `internal/parser`: handwritten PostgreSQL-oriented lexer, goyacc grammar/checked-in generated parser and closed schema/table CREATE, ALTER/DROP SCHEMA, DROP TABLE, INSERT/SELECT/SET/RESET/SHOW/setting-call/bounded single-target LOCK TABLE AST. Parse entire input, never execute a prefix while ignoring a suffix. Source positions and parameter indices belong in AST, not SQL substring counting. Ordinary-string mode and command context are per-call options, never globals.
- `internal/engine`: synchronized process-local catalog, immutable committed values, statement-atomic execution, parameter inference, snapshots and lifecycle publication.
- `internal/sqlstate`: shared error contract; root Error aliases it. SQLState is the compatibility interface, not concrete pq.Error.
- `smoke/*_test.go`: real public API proof; production imports are standard library/module only.

Production must have zero external dependencies. goyacc is generation-only; lib/pq, sqlmw and testcontainers stay in tests. Keep engine/parser independent of root adapters. Reuse these seams rather than introduce alternative binders or storage paths.

## Supported surface and limits

CREATE TABLE supports unqualified or schema-qualified names with INTEGER/INT/INT4, BIGINT/INT8, TEXT, BOOLEAN/BOOL and optional NULL/NOT NULL; INSERT VALUES supports optional target columns/multiple rows; SELECT supports star or scalar literal/unqualified-column/parameter targets with FROM, optional column=literal/parameter predicate or bare scalar WHERE in contextual BOOL, and one ORDER BY key ASC/DESC. No no-FROM scalar expansion or equality projection. Values are signed-64 integers, standard quoted strings, TRUE/FALSE/NULL and 1-based `$n`. Quoted identifiers, nested comments, doubled quotes/apostrophes and newline string concatenation follow README's C-locale UTF8 subset. Unresolved output parameter occurrences fall back to TEXT after filter analysis, retaining their initially known type: a target-first unknown occurrence conflicts with a later non-TEXT constraint (`42P08`), while TEXT target/filter reuse works. Same-context repeats work, unused gaps fail, mixed assignment destinations remain unsupported. Text/parameter inputs coerce through type input functions; INSERT assignment casts and WHERE operator checks differ. NULL equality is unknown and is not true; WHERE keeps only TRUE. ASC NULLS LAST/DESC NULLS FIRST remain.

CREATE TABLE uses ordered explicit columns and plain LIKE elements, including multiple/interleaved sources and zero-column `()`. LIKE copies declaration shape and NOT NULL, never source rows/owner/ACL/dependencies; qualified/effective-path lookup requires source namespace USAGE and relation SELECT. LIKE options remain unsupported, not successful no-ops. IF NOT EXISTS skips an existing authorized destination before semantic element analysis, including nested CREATE TABLE in CREATE SCHEMA; malformed syntax still fails before effects. Nested elements use the enclosing owner and local staged schema path, never change session identity/settings, and publish atomically. Outer CREATE SCHEMA IF NOT EXISTS still cannot contain elements.

DROP TABLE supports grouped schema-qualified/path targets, IF EXISTS and RESTRICT/CASCADE with whole-group atomic preflight. Table owner, schema owner or superuser authority is required. The current inbound table-definition dependency set is empty, so both drop modes remove the same explicitly selected tables/contained metadata/storage/ACLs, not schemas/types/roles/independent LIKE clones. Retained Rows survive removal. Public DROP TABLE remains excluded from private Restore.

Do not widen syntax beyond the documented selected surface: no SQL transaction controls/savepoints, aliases, general casts/joins/functions/expressions, relation defaults, serial, primary keys, UPDATE/DELETE/RETURNING or extra clauses. Driver BeginTx/Commit/Rollback supports READ COMMITTED baseline INSERT/SELECT and the AX utility below; explicit CREATE/ALTER/DROP SCHEMA and CREATE/DROP TABLE, role/session-authorization utilities and SET/RESET/SHOW/setting calls remain native unsupported boundaries. Session settings use the shared registry/binder and catalog-resolved sqltype descriptors/values. Driver.RegisterSetting publishes copied dotted typed definitions before first Engine construction, then freezes. Seven honest builtins are application_name, client_min_messages with notice filtering, search_path, standard_conforming_strings, statement_timeout, read-only UTF8 server_encoding and deny-only log_statement_stats. Settings add no privileged authority, transaction-local restoration or file/process effects; preserve existing role/ACL capabilities. See README for units, bounds, diagnostics and physical-session behavior. Recognized unsupported features fail `0A000`; malformed supported syntax fails `42601`. Commands accept at most one statement except Restore. Caller context cancellation stays ordinary; only own setting timers return 57014. Failed multirow INSERT must not partially publish data.

Relation locking is exactly transaction-owned AS for SELECT, RX for INSERT, and explicit single-target `LOCK TABLE name IN ACCESS EXCLUSIVE MODE` in an explicit block under the current superuser role. AS/RX coexist; AX conflicts across owners; same-owner operations reenter. Semantic SELECT/INSERT Prepare acquires AS/RX (implicit Finish releases, explicit retains despite stmt.Close); LOCK Prepare is metadata-only. Abort/end immediately releases exact owner state; commit publishes before waking successors. Pending context cancellation removes requests. Successful replacement fences old held/waiting epochs outside metadata locks; implicit SQL waits drop replacement admission and revalidate exact identity afterward. Do not add other modes, NOWAIT, lock timeouts, conversion/deadlock detection, row/advisory resources or introspection.

CREATE/ALTER/DROP SCHEMA and search_path/current_schema reuse existing catalog/session/role seams. Nested CREATE SCHEMA elements are CREATE TABLE only with atomic publication. Schema provisioning/rename uses effective-superuser database-CREATE baseline; fixed native database label stuntgres is diagnostic-only. Native public retains PUBLIC USAGE|CREATE. Prepared AST re-resolution has a coherent frozen signature guard, not full PostgreSQL cached-plan caveat parity. Absent pg_temp lookup never allocates; pending creation fails 0A000.

DSNs are exact opaque process-local names, including empty string, scoped to a Driver. Different strings/Drivers isolate data. Closing pools/connections does not erase an engine. Reset atomically clears objects retaining process-local identity. Dump serializes persistent user schemas before owner-grouped qualified tables/rows; unsupported explicit ACLs fail before output. Restore stages and atomically replaces, preserving independently mapped namespace/table owners through private stage-only destination authority, never fake grants. Controls require native pools, reject wrapped/foreign drivers and nil inputs, and preserve data on errors. Snapshots survive controls and schema lifecycle changes. Never hold target locks during external I/O.

Trusted Restore INSERT uses a local validated captured-bootstrap AuthorizationView, never session identity mutation. Named CREATE owner groups remain intact; per-statement private markers cannot affect public Prepare/INSERT or persist schema/table ACL grants.

Restore's initialized private catalog accepts CREATE/ALTER/DROP SCHEMA, CREATE TABLE, literal INSERT and named SET SESSION AUTHORIZATION only. Dump reconstructs bootstrap identity/name/owner changes before user objects; retained canonical builtin ACLs transform owner grantor/grantee, recreated public has absent ACL, and unchanged bootstrap retains legacy bytes. Arbitrary explicit ACL serialization stays unsupported. Held INSERT rebinding INT4→TEXT rejects native 0A000 before importer/write; pinned PostgreSQL retains INT4 parameters and assignment-coerces to TEXT, an explicitly asserted difference.

## Commands and proof

Run from repository root with Go >=1.26:

```sh
make generate
make test
make reference
make smoke
make bench
go test -race ./...
go list -deps -f '{{if not .Standard}}{{.ImportPath}}{{end}}' ./...
```

Make commands expand respectively to `go generate ./internal/parser`, `go test ./...`, `go test -tags reference -run TestReference -count=1 -v ./reference`, `go test -count=1 -v ./smoke`, and `go test -run '^$' -bench '^BenchmarkOpenDatabase$' -benchmem -count=5 .`. Generation uses `golang.org/x/tools/cmd/goyacc@v0.50.0`; checked-in output must compile. Production dependency output may contain only this module's paths. Benchmark actual fresh engines through Ping and Close, not merely lazy sql.Open; report ns/op and allocations against <1ms target.

Tests must specify expected outcomes independently, not parity alone. Cover consumer-visible boundaries, errors, atomicity, parameter direct/prepared behavior, cursor metadata/cancellation/EOF, shared pools and isolated instances, and destructive-control round trips/failures. Public smoke assertions run as unit tests in `smoke/*_test.go`, with failures and success reported by Go test rather than printed success labels. Do not replace actual behavior with mocks or test source text/wiring counts.

Reference tests live in the dedicated `reference/` external test package gated by `reference`, using only the public stuntgres API. `reference/fixture_test.go` owns shared setup and helpers; functional groups live in separate test files of at most 750 lines each. One bounded-lifecycle PostgreSQL 18.0 container serves serialized fixtures; pin README's image digest and UTF8/C locale. Reset public schema before/after fixtures with privileged unwrapped pq; close case handles/rows first. Use sqlmw wrapping memory and pq for execution, record through context on both direct/prepared hooks and own copied row buffers, retaining a native memory pool for controls. Do not compare implementation call counts. Docker/image failures in an explicitly enabled suite must be visible, never skipped or mocked.
The cohesive common `reference/fixture_test.go` is exempt from the 750-line limit. Keep reference tests independent of root-private test helpers and internal stuntgres packages; public driver, error, notice and native control APIs are allowed.
